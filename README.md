Repositorio dedicado al estudio, desarrollo e implementación de soluciones de **ingeniería computacional**, enfocadas en optimización de software, arquitectura de computadores, procesamiento paralelo, algoritmos avanzados y aprovechamiento eficiente de los recursos computacionales.

El objetivo es comprender cómo diseñar y construir sistemas capaces de ejecutar operaciones complejas con eficiencia, precisión, escalabilidad y alto rendimiento.

---

## 🎯 Objetivo

Fortalecer conocimientos en ingeniería del rendimiento computacional mediante el desarrollo de algoritmos, estructuras de datos, simulaciones y sistemas optimizados.

Se busca explorar la relación entre software y hardware, comprender los mecanismos internos de ejecución de los programas y aplicar técnicas que permitan mejorar el rendimiento de las soluciones tecnológicas.

## 📚 Líneas de desarrollo

### 1. ⚡ Performance Engineering

- Análisis de complejidad temporal y espacial.
- Optimización de algoritmos.
- Benchmarking y medición de rendimiento.
- Identificación de cuellos de botella.
- Eficiencia computacional.

### 2. 🧮 Data Structures & Algorithms

- Listas enlazadas, pilas y colas.
- Árboles y grafos.
- Algoritmos de ordenamiento y búsqueda.
- Algoritmos de recorrido.
- Análisis de complejidad computacional.

### 3. 🧠 Memory & Resource Management

- Gestión dinámica de memoria.
- Punteros y referencias.
- Administración del ciclo de vida de objetos.
- Smart pointers.
- Optimización del consumo de recursos.

### 4. 🔄 Parallel & Concurrent Computing

- Procesamiento multihilo.
- Sincronización de procesos.
- Distribución de tareas.
- Paralelización de algoritmos.
- Introducción a OpenMP y CUDA.

### 5. 🖥️ Computer Systems & Architecture

- Organización y arquitectura de computadores.
- Procesadores y memoria caché.
- Jerarquía de memoria.
- Sistemas operativos.
- Interacción entre software y hardware.
